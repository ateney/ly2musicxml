ly2musicxml

LilyPond (.ly) の楽譜ソースをその場で MusicXML に変換。MuseScore / Finale / Sibelius で直接開けます。

🔒 すべての処理はブラウザ内 (WebAssembly) で完結。ファイルはどこにも送信されません。
📄 .ly ファイルをドラッグ＆ドロップ、またはクリックして選択
Python (Wasm) を初期化中… 

    

  


  

    対応機能と使い方
    
    
      
  • 対応: 相対音程 (\relative)、和音、タイ、スラー、連符 (tuplet)、\repeat unfold、ピックアップ小節 (\partial)、調・拍子・テンポ変更、強弱記号、ヘアピン、アーティキュレーション、音部記号、\ottava
    • 
      
  • 構成: <name>_begin ブロックと <name>_violin_a など各パート変数を自動検出します
    • 
      
  • 1ファイルに複数楽章があれば、楽章ごとに .musicxml を書き出します
    • 
      
  • CLI 版 (ly2musicxml.py) も同梱: python ly2musicxml.py movement-1.ly -o out.musicxml
    •
